# OS 0.7.0 本機實作紀錄

日期：2026-09-27。這是合併前的本機驗證紀錄；本批未建立正式版本標籤，Core 仍為 0.6.0，OS 已發布標籤仍為 os-v0.6.0。

## 已完成

- Workspace 的 WORKLOGIC、單案面板與樣式抽成共用檔。③直接管理整合概況、同意與任務；④直接管理決策、時間軸與歸因。①保留樓層面積示意，②保留財務快照。Workspace 保留選案與檔案進出，舊 `?view=` 連結轉回四步。
- ③預設開啟案件紀錄，使用者可切換既有整合推演；示意推演有獨立標示。新增的控制項支援鍵盤與窄版。
- 儲存失敗保留輸入；外部分頁更新或切換案件時阻擋過時表單寫入，明示重新讀取。歸因忽略已換案件、換方案、換面板或結束生命週期的非同步回應。風險判定沿用 CaseBus 的輸入／Core 二元組綁定守衛。
- ①的次要入口可開啟獨立合成 3D：立體／俯視、旋轉、平移、縮放、物件聚焦、總覽、顯示切換與完整重置。隱藏物件的填色、邊線與點選一起停用。
- 來源版本、單位、座標系、幾何指紋、輪廓頂點與明示高度可直接對照；3D 相依檔不可用時仍可選取並閱讀物件資料。原型不讀寫案件、選配或 Activity。

## 保留的資料界線

沿用 [Schema Audit](../architecture/VISUALIZATION_FOUNDATION_0_7.md) 與 [Three.js ADR](../architecture/ADR_THREEJS_VISUALIZATION.md)。正式幾何契約、來源與案件 Viewer 依賴例外仍為下一階段門檻。本批沒有修改 Core、凍結 Schema、版本徽章或 Pages 部署設定。

合成 3D 不代表任何正式案件的 LOD 0。缺少可靠輪廓與高度時維持面積示意；沒有戶別幾何及選配映射時不定位地主。`eligible_units` 不作為已選屋配置。

## 預覽

先執行 `python tools/prepare_spatial_prototype.py`；需要本機 Core 時另執行 `python tools/prepare_pyodide.py`。
執行 `python tools/serve_web.py --port 8766`，開啟 `http://127.0.0.1:8766/dashboard.html`。
3D 展示為 `http://127.0.0.1:8766/spatial-prototype.html`。本紀錄的本機驗證不代表已通過遠端 CI 或部署；後續推送、合併與部署狀態以 GitHub PR／Actions 為準。
