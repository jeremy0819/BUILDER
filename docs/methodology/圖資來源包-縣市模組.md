> **文件類型**：方法論（docs/methodology/）
> **來源**：使用者提供之圖資清單（2025-03 版）＋本文重整
> **狀態**：連結**未逐條實測**；標示 ⚠️ 者為本文發現的結構性問題，須人工複核
> **與 M8.5 的關係**：這份清單就是「使用者本機匯入 GeoJSON」時**該匯入哪些圖層**的規格來源

## 0. 這份清單在做什麼

論文附錄 A 已有**法源包**（每條會影響面積、成本、程序的法規都要有可點開的來源與版本）。
本文是它的**視覺對應物——圖資包**：每一張會影響判斷的圖，都要有**可點開的官方出處**。

兩者是同一條紀律的兩面：

```
法源包：這個數字憑哪一條法規？   →  條號＋版本＋查證日
圖資包：這條線憑哪一張官方圖？   →  系統名＋連結＋圖資年度
```

> **為什麼要成包**：敷地計畫不是一張圖，是**十幾張圖疊出來的一個主張**。
> 少一張，主張就有一個沒有出處的斷點——而審議委員問的往往正是那個斷點。

## 1. 五層取用順序（這是「思維」，不是清單）

清單本身按縣市排，但**實際作業要按功能分層**，因為上一層的答案是下一層的輸入：

| 層 | 回答什麼 | 典型圖資 | 錯了會怎樣 |
|---|---|---|---|
| **① 定位** | 這塊地在哪、屬於哪個計畫 | 區位圖、更新地區／更新單元、都市計畫列表 | 整個案子建在錯的計畫上 |
| **② 權屬** | 誰的地、範圍到哪 | 地籍圖、地號／建號、公有地、新舊地號、建物套繪 | 分母錯 → 同意率、分配全錯 |
| **③ 管制** | 能蓋什麼、不能蓋什麼 | 使用分區、都審範圍、機場／捷運禁限建、土壤液化 | 量體算完才發現不能蓋 |
| **④ 現況** | 現在長什麼樣、有什麼證據 | 地形圖、門牌、使（建）照存根、管線、歷史圖資 | 拆遷補償與現況對不上 |
| **⑤ 試算連動** | 這些圖如何變成錢 | 鄰房鑑定框選範圍 → 共同負擔 C 科目 | 費用提列沒有範圍依據 |

> **第 ⑤ 層是這份清單最容易被低估的一項**。臺北市那條「鄰房鑑定框選範圍」被單獨列在
> 「以下是共同負擔試算使用」之後——它不是背景資料，是**直接餵進共同負擔提列的輸入**。
> 圖資與財務在這裡接上，而這正是本專案 Core 的邊界所在。

## 4. 本文發現的清單品質問題（須人工複核）

| 問題 | 位置 | 影響 |
|---|---|---|
| **內嵌 ASP.NET session id**（`(S(…))`） | 臺北 使用分區圖、機場禁限建；新北 機場禁限建 | session 過期後連結失效，點了會被導回首頁或報錯 |
| **錯誤頁路徑＋網址重複串接** | 桃園 土地使用分區圖 | 直接打不開 |
| **系統名與網址不符** | 桃園 地籍圖／地籍套繪圖 | 照名字找不到、照網址對不上名字 |
| **項次斷裂**（由 6 起跳） | 桃園 | 前 5 項圖資不明，可能漏掉定位與權屬層 |
| **缺漏縣市** | 臺中（0）、新竹（1） | 無法支援該市案件 |

> ⚠️ **本文未逐條實測連結可用性**。上表只列出**不必連線即可判定**的結構性問題；
> 其餘連結是否仍有效、圖資年度是否更新，須由使用者實地點過並回填查證日。

## 5. 與 BUILDER 的接點

| 接點 | 說明 |
|---|---|
| **M8.5 GIS（方案 B 本機匯入）** | 本清單＝「使用者該匯入哪些圖層」的規格來源。M8.5 只接受本機 GeoJSON、不連外抓圖磚——**本文所有連結都是人去取圖的地方，不是系統去打的 API** |
| **共同負擔 C 科目** | 鄰房鑑定框選範圍 → 拆遷補償與權變費用的範圍依據 |
| **法源包（論文附錄 A）** | 兩者並用：法源包管「憑哪條法規」，圖資包管「憑哪張官方圖」 |
| **資料紅線** | 這些是**公開入口網址**，非案件資料，可進版控。<br>但**由此下載的地籍圖、產權清冊、門牌資料一律不得進版控**——那是 Gate 0 結構式守衛（`tools/check_real_data_patterns.py`）與圖檔白名單（Gate 8）共同守的線 |

## 6. 誠實限制

- 本文是**取圖的地圖**，不是**畫圖的準則**。它告訴你去哪裡拿哪張圖，
  **不告訴你這些圖怎麼組合成一張會過的敷地計畫**——後者須以實際圖面為據，另行整理。
- 清單版本為 2025-03；政府系統改版頻繁，**連結與圖資年度都會過期**，
  使用前請確認，並把查證日回填。
- 各系統的圖資精度、更新頻率與法定效力不同（例如「地形圖 112 年為最新年度」）。
  **早期試算可用，但送審一律以主管機關核發之正式圖說為準。**
