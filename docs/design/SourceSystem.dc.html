來源語意系統
Provenance as Visual System
這個產品最特別的紀律是「每個數字都要說出自己從哪來」。視覺系統的核心不是配色，是 讓來源看得見——只有三種，沒有第四種。
CORE
計算核心
由 core/redcf 算出的權威數字。允建容積、銷售坪數、共同負擔比、全案投報率。
介面一律逐欄搬運，不得換算。
全案投報率 179.9% CORE
INPUT
你的輸入
使用者登打的事實——基地面積、容積率、戶數。抄謄本抄來的，不是算出來的。
計算核心不可用時仍可記錄，因為它本來就不需要計算。
基地面積 1,800 ㎡ INPUT

GO／CAUTION／STOP、完工機率、破局引爆點。
