建案入口 5 → 1
目前 5 個頁面都能建案。只有起始頁真正建案，其餘改為跳轉。 功能一項不減，要記的概念從 5 個變 1 個。
收斂原則：每一步只回答一個問題，答完才進下一步。 判斷某個區塊該放哪一步，就問「它幫使用者回答的是哪一個問題」——回答不了就不屬於主動線，收進摺疊或案件櫃。

量體與階段交棒（2026-09-22 至 09-23）

  • ① 主區為「案件快照／本次草案」同尺度樓層比較；寬度表達輸入面積比例，非真實平面或建築高度。地政、清冊、歷程及已存快照明細收合，功能保留。
  • 規則生成或逐層輸入立即更新草案圖；自動重算以去抖呼叫真 Core。輸入一變，舊結果立即失效；等待、失敗與缺值均不補數字。
  • 「採用草案，前往②產品」為唯一的量體採用命令；預覽不寫案件。採用前核對作用中案件、完整 engine 及快照溯源，拒絕覆蓋其他頁面較新的輸入。
  • ② 預設顯示真 Core 財務調整及案件快照／本次試算比較；教學與匯入收進參考入口。採用後沿用原案件 ID 前往③，變更輸入使舊判定解除綁定。
  • 圖面只支援選層，不提供拖曳反算。手機另有樓層選單；桌機與手機均驗證不溢出。③手機盤面改為六欄，保留全部戶別並維持觸控尺寸。
  • ①逐層微調預設收合，選圖才展開；②主視圖不重複顯示快照 KPI，詳細教學另列參考。自動重算可關閉，關閉時取消尚未執行的排程。
  • 本輪不更動 Core、凍結 schema 或 Pages 部署。Workspace 面板搬移、GIS 與企業資安能力仍是獨立階段，不以本輪 UI 完成代替。
