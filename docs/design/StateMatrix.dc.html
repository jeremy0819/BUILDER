綁定 ≠ 不陳舊
0.4.0 的判定配 0.4.0 的快照，是一致的歷史配對，綁得上。 但現行 Core 是 0.6.0——數字沒錯，公式已經換過。
⚠ 數字來自 Core 0.4.0 快照（現行 0.6.0）
陳舊時在導覽列說明列常駐標示；不隱藏數值，因為它仍是當時的事實。
貫穿全矩陣的一條：未校準標示
stage_tree.json 自述「p_survival 仍為示意預設，尚未經真實成敗案校準」， 而它正是 GO／CAUTION／STOP 的來源。凡顯示 verdict、完工機率、EV 之處一律附標示， 文字取自 Core 的 _note，不由各頁自己寫一份。 目前 ④ 的四象限圖與導覽列都沒有這個標示。
